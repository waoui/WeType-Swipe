# 微信输入法滑动快捷键

为安卓版微信输入法增加**上滑／下滑独立自定义动作**的 LSPosed 模块。

支持 26 键与九宫格，分别配置上滑和下滑动作：编辑操作、原生剪贴板、常用语、固定文本和内置模块设置。正常点击保留原有输入；原下滑配置升级后继续有效。

## 主要功能

### 快捷操作

- 全选、剪切、复制、粘贴
- 复制全部、剪切全部
- 移动到段首、段尾
- 选择当前位置到段首、段尾
- 移动到整篇文本的文首、文尾
- 选择当前位置到整篇文本的文首、文尾
- 打开微信输入法原生剪贴板
- 打开微信输入法原生快捷发送／常用语
- 撤销、重做
- 下一个输入法、上一个输入法、系统输入法选择面板
- 输入指定内容：每个按键可保存独立文本，支持中文、英文、数字、符号、Emoji 和换行
- 禁用指定按键的某个滑动方向
- 打开内置模块设置，可绑定到任意支持的上滑或下滑键位（默认 L 下滑）

### 键盘与手势

- 支持 26 键字母区与九宫格数字键 2–9
- 每个键位的上滑、下滑动作、标签和固定文本可分别配置，彼此独立
- “输入指定内容”可同时绑定多个按键，每个按键内容互不影响
- 26 键与九宫格可分别调整触发距离
- 支持竖屏、横屏、横屏悬浮键盘与分离键盘
- 键帽**上方显示上滑功能文字，下方显示下滑功能文字**
- 可长按按键设置自动、自定义或隐藏标签
- 原生剪贴板与快捷发送无需显示在输入法工具栏

### 设置与隐私

- 设置页使用“26 键 / 九宫格 / 手势与选项”三栏分页，底部保存按钮固定可见
- **仅微信输入法内置设置编辑实际配置**；独立模块 App 仅提供维护、旧配置备份和故障恢复，不再维护第二份可编辑配置
- 内置设置可在微信输入法“关于”页面连续点击图标 5 次打开；也可为 L 键下滑或任意方向绑定“内置模块设置”快捷入口
- 可关闭模块主动震动
- 可独立开关按键功能文字与滑动触发提示
- 内置设置可通过系统文件选择器导出／导入 UTF-8 TXT（需由微信输入法 Activity 承载），也可复制配置／从剪贴板导入
- 独立模块维护页可导出升级前的旧模块配置，**不代表当前生效的输入法配置**
- 独立模块维护页可隐藏桌面图标，并从 LSPosed 模块设置重新进入
- 模块不联网，不采集或上传实际输入内容
- “输入指定内容”由用户主动配置，实际生效配置只保存在微信输入法私有存储中

## 安装与使用

1. 安装最新版正式 APK，在 LSPosed 中启用模块并将作用域勾选为“微信输入法”。
2. 重新启动微信输入法进程，或重启设备。
3. 打开独立模块 App 中的 **“打开内置模块设置”**；也可从微信输入法“关于”页连续点击图标 **5 次**，或使用已经绑定的 L 键下滑进入。
4. 在唯一的内置设置页中按“26 键 / 九宫格 / 手势与选项”配置上下滑动作，点击底部 **“保存并应用配置”**。
5. 在内置页面的“手势与选项”中导出当前配置 TXT。输入法悬浮窗口无法调用系统文件选择器时，可以先使用剪贴板复制配置保存。

**升级须知：** 从 v1.12.0 升级前请先保存已有配置文本。v1.13.0 已经有微信输入法私有配置时保留原样；仅当输入法侧没有历史设置，才尝试从旧模块 App 一次性迁移。旧模块历史数据保留，不会自动删除。

## 界面与数据源

- **内置设置（唯一编辑入口）**：编辑 26 键与九宫格上下滑、标签和固定文本；提供 TXT/剪贴板配置导入导出。
- **独立模块（维护入口）**：打开内置设置、导出升级前的旧配置、复制诊断信息、隐藏/显示桌面图标，不再显示另一份可能过期的按键绑定。
- **数据源**：微信输入法进程内部的配置存储。模块不将实际输入内容发送到网络。

## 默认配置

**仅全新用户**使用以下推荐下滑预设；升级已保存的配置不会覆盖原映射。设置页可以手动点击“应用推荐下滑预设”，该操作仅改动 26 键下滑，不影响上滑或九宫格。

| 按键 | 下滑动作 | 按键 | 下滑动作 |
| --- | --- | --- | --- |
| A | 剪贴板 | S | 常用语 |
| D | 撤销 | F | 重做 |
| G | 段首 | H | 段尾 |
| J | 文首 | K | 文尾 |
| **L** | **内置模块设置** | Z | 全选 |
| X | 剪切全部 | C | 复制全部 |
| V | 粘贴 | B | 禁用下滑 |
| N | 选至文首 | M | 选至文尾 |

其他 26 键、全部上滑和九宫格默认未绑定。

## v1.13.0 更新内容

- 取消第二套独立配置编辑器；微信输入法内置页面是唯一设置界面，解决两边键位显示不同步的结构性问题。
- 独立维护页采用更清晰的分区布局和主操作入口，单独标识旧配置备份和实际配置的区别。
- 内置设置优化上／下滑清空分组、推荐默认预设、固定保存栏与导入导出按钮布局。
- 内置 Activity 页面支持 TXT 文件导入导出；悬浮窗口保留剪贴板备份兼容方案。
- 已有内置配置优先；必要时安全迁移旧模块历史数据，原手势动作 ID 0–24 保持不变。
- 自动化测试及构建验证不等于真实机型验证：新 TXT 文件选择器与旧配置迁移仍建议在手机上验收。

详见 [v1.13.0 Release](https://github.com/waoui/WeType-Swipe/releases/tag/v1.13.0) 和 [更新记录](CHANGELOG.md)。

## 兼容性

- Android 9 及以上（API 28+）
- LSPosed 环境
- 安卓版微信输入法
- 历史功能兼容验证包括：微信输入法 3.5.0、3.5.2、4.0.0，Android 16；**本版新设置与文件选择器路径仍需手机实测**

微信输入法升级后，内部实现变化可能影响原生剪贴板、快捷发送或界面匹配。如遇兼容问题，请在 Issues 中附上微信输入法版本、Android 版本、LSPosed 日志和复现步骤。

## 构建

构建环境：

- JDK 17
- Android SDK 35
- Gradle 8.9

Modern Xposed API 以 `compileOnly` 方式引入，不会打包进 APK。

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

Windows 可将命令中的 `./gradlew` 改为 `gradlew.bat`。版本号统一维护在 `gradle.properties` 的 `VERSION_CODE` 和 `VERSION_NAME` 中。

### 发布正式版

1. 更新 `VERSION_CODE`、`VERSION_NAME`、`CHANGELOG.md`、`README.md` 和对应的 `RELEASE_NOTES_v版本号.md`。
2. 合并代码并等待持续集成通过。
3. 在 Actions 中手动运行“构建并发布正式版”，或由仓库所有者创建标题为 `Publish v版本号 final` 的安全发布触发 PR／Issue。
4. 工作流从 `main` 检出正式源码，执行单元测试、Lint、正式签名验证，并上传 APK、源码 ZIP 和 SHA-256 校验文件。

历史版本说明以 GitHub Release、Tag 和 `CHANGELOG.md` 为准；已发布旧版本的 `RELEASE_NOTES_v*.md` 无需长期保留在 `main`。

未配置正式签名环境变量时，构建产物不会使用项目的发布证书。正式 Release 由 GitHub Actions 使用仓库 Secrets 自动签名、校验并发布。
