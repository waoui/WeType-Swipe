# 微信输入法滑动快捷键（WeType-Swipe）

给安卓版微信输入法增加 26 键和九宫格 **上滑 / 下滑独立快捷动作** 的 LSPosed 模块。

- 上滑、下滑分别绑定功能，支持独立的自定义固定文本和标签。
- 功能标签按方向显示：**上滑在字母上方，下滑在字母下方**。
- L 键下滑可进入内置模块设置；可修改任何支持的键位。
- **v1.13.0 起只有微信输入法内置设置可以编辑配置**，独立模块 App 为维护与恢复中心，不再维护第二份配置。

## 设置入口

### 首选：微信输入法内置设置

1. 安装 APK，在 LSPosed 中启用模块，作用域选择 **微信输入法**。
2. 强制停止并重新打开微信输入法，或重启设备。
3. 在微信输入法键盘上 **L 键下滑**（仅当该绑定已配置），打开内置模块设置；也可在微信输入法的 **关于页面连续点击图标 5 次**。
4. 在「26 键 / 九宫格 / 选项与备份」三页完成设置，点击底部「保存并应用配置」。

若 L 键未绑定或入口受 ROM 限制，请使用关于页五击入口。

### 独立模块 App：维护中心

从桌面或 LSPosed 中打开模块 App，可执行：

- 跳转 **微信输入法内置设置**（若目标 App 不允许跳转，请使用关于页五击）。
- 导出升级前**独立 App 的历史配置**到 TXT，供迁移检查与回滚使用。
- 复制不含按键文本、密码或其他隐私内容的模块诊断信息。
- 切换桌面图标显示 / 隐藏；隐藏后仍可从 LSPosed 打开。

**独立模块 App 不再编辑、保存或展示 26 键和九宫格当前映射。** 历史备份不等于输入法当前生效配置。

## 主要功能

| 功能 | 说明 |
|---|---|
| 双向动作 | 26 键 A–Z、九宫格 2–9 分别配置上滑与下滑 |
| 编辑快捷键 | 全选、复制、剪切、粘贴、复制全部、剪切全部、撤销、重做 |
| 位置和选区 | 段首、段尾、文首、文尾、选择至文本位置 |
| 输入法功能 | 原生剪贴板、常用语/快捷发送、输入法切换 |
| 自定义文字 | 每键每方向独立文本，支持中文、Emoji 和换行 |
| 键帽提示 | 上滑标签显示在键帽上方、下滑在下方；标签支持隐藏和自定义 |
| 设置快捷入口 | 绑定「内置模块设置」，推荐 L 键下滑 |
| 触发选项 | 26 键和九宫格独立触发距离、振动、按键标签和触发提示 |
| 备份恢复 | 内置设置中的 TXT 文件导入导出与剪贴板复制/导入 |

内置设置在**微信输入法 Activity 页面**承载时支持 Android 系统文件选择器。若由 **输入法悬浮窗口**承载，使用剪贴板备份与恢复；此模式不显示无法完成的文件选择器入口。

## 默认下滑预设

仅首次没有现有配置时使用推荐预设。覆盖安装已有版本时，**优先保留输入法当前生效配置**，不自动覆盖为预设。内置设置可以主动应用推荐键位，确认后需点击底部保存。

| 按键 | 下滑动作 | 按键 | 下滑动作 |
|---|---|---|---|
| A | 剪贴板 | S | 常用语 |
| D | 撤销 | F | 重做 |
| G | 段首 | H | 段尾 |
| J | 文首 | K | 文尾 |
| **L** | **内置模块设置** | Z | 全选 |
| X | 剪切全部 | C | 复制全部 |
| V | 粘贴 | B | 禁用下滑 |
| N | 选至文首 | M | 选至文尾 |

其他 26 键、所有上滑、九宫格默认不绑定。

## v1.13.0 架构与界面更新

- **唯一生效配置源**：微信输入法私有配置，内置页面直接编辑、保存；不再将完整配置镜像到独立模块 App。
- **兼容升级**：如果目标输入法尚未保存配置，可以从旧模块 App 已保存的配置执行一次性迁移；已有目标配置绝不被历史数据覆盖。
- **维护中心重新设计**：主入口清楚展示，诊断与历史备份分区，支持亮色 / 深色和更易点击的触控区域。
- **内置设置优化**：清楚标注 ↑上滑 / ↓下滑标签位置；推荐键位应用前确认；备份文件管理成为独立卡片，文件备份优先。
- **完整 TXT 备份**：统一在内置设置中导入导出当前实际配置，包含动作、标签、文本和手势参数；导入前校验格式并要求确认。
- 不修改原有动作 ID 0–24、触摸动作实现、密码输入框保护和键帽方向绘制规则。

详细更新：[v1.13.0 Release](https://github.com/waoui/WeType-Swipe/releases/tag/v1.13.0)、[CHANGELOG](CHANGELOG.md)。

## 兼容性及已知限制

- Android 9 及以上（API 28+）；需 LSPosed + 安卓版微信输入法。
- 过往版本曾验证微信输入法 3.5.0 / 3.5.2 / 4.0.0 及 Android 16；**v1.13.0 的单一配置迁移、内置文件选择器和界面改造仍缺少真实设备完整回归**。
- Android ROM 或微信输入法的 Activity 生命周期变化可能影响直接跳转和文件选择器回调，遇问题建议保留 LSPosed 中 `WeTypeSwipe` / `WeTypeSwipeFile` 日志。
- 升级前建议先备份当前配置。如果 Android 阻止安装较低版本，不要通过直接卸载来降级，以免清空私有数据。
- 模块不联网、不上传输入内容或配置。TXT 文件由用户主动选择保存位置。

## 构建与发布

环境：JDK 17、Android SDK 35、Gradle 8.9。

```bash
./gradlew --no-daemon --stacktrace clean testDebugUnitTest lintRelease assembleRelease
```

Windows 可使用 `gradlew.bat`。正式版签名存储在仓库受保护的 GitHub Actions Secrets 中，不在源码仓库内。

正式发布流程：更新 `gradle.properties`、README、CHANGELOG、`RELEASE_NOTES_v*.md`；通过 PR CI 后合并 `main`；打开 **Actions → 构建并发布正式版 → Run workflow**（选择 `main`、输入不含 `v` 的版本号），由仓库受保护工作流验证原永久签名并发布 APK、源码 ZIP 和 SHA256。**不再创建发布 Issue 或发布触发 PR。**

反馈请使用 [Issues](https://github.com/waoui/WeType-Swipe/issues) 中的缺陷或功能建议模板；旧发布触发记录已加 `release-automation` 标签，历史版本在 [Releases](https://github.com/waoui/WeType-Swipe/releases)。分类及筛选见 [Issues 整理说明](.github/ISSUE_GUIDE.md)。
